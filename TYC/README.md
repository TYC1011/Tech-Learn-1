# 勇者算術大冒險：拯救王國四則運算 (Pixel RPG Math Game 2.0)

一款專為**國小四年級下學期數學【整數四則運算】**設計的像素復古 RPG 冒險遊戲。
針對學生在學習混和四則運算時，常忘記「**先乘除後加減、括號要先算**」之痛點進行情境化遊戲教學。

---

## 🎮 2.0 全新動態冒險升級亮點

### 1. 全裝置最佳尺寸 (電腦、平板、手機自適應)
- 採用彈性動態響應式佈局（Responsive & Adaptive Design），自動偵測螢幕寬高。
- 手機直屏或橫屏自動排版、觸控按鈕加大（$\ge 44\text{px}$）方便拇指點擊；平板與電腦保持大氣視野與高畫質 SVG 渲染。

### 2. 生動角色與關卡動態特效 (2D 橫向卷軸冒險風格)
- **黑熊與魔龍原版 Emoji 回歸**：
  - 第一關黑熊採用經典活潑的 `🐻` emoji，搭配原地跳動與撲擊動作。
  - 魔王關魔龍採用震撼的 `🐲🔥` emoji，具備浮空喘息、龍焰噴吐與受創震顫特效。
  - 勇者維持高精細帥氣向量設計（金冠紅寶石、刺蝟金棕髮、紅披風、神劍金盾），完美契合勇者形象。
- **Level 1 迷霧森林**：
  - 畫面上下雙重樹林向左流動滾動，勇者與黑熊原地跑步彈跳。
  - A/B/C 路線抉擇，勇者奔跑穿行；支援點選或鍵盤 `1/2/3`、`A/B/C`。
  - 順利進入下一條路時倒數 3 秒，**可按空白鍵或 Enter 鍵立即跳過**！
- **Level 2 魔法村莊**：
  - 祭壇上的神劍在**答對融合時閃爍黃金光芒（閃黃光）**！
  - **選錯順序時神劍劇烈閃紅光並震顫**！錯題採用生動彈跳視窗詳細提示運算順序。
- **Level 3 神殿祕寶 (2D 橫向卷軸地城闖關)**：
  - 採用經典 **2D 橫向卷軸地城**視覺：石壁符文遠景向左流動、橫向平鋪石板地面滾動、兩側火把燃燒！
  - **主角勇者不斷前進開門**：勇者奔跑至第 1 扇 ~ 第 9 扇神殿封印石門，答對石門升起勇者穿過。
  - **第 10 題開啟寶藏**：最終第 10 題化身為「💎 遠古祕寶神殿金庫」，正確解答後寶藏破門而出，伴隨神聖金光與【重生之盾】升起！
  - 支援鍵盤數字鍵 `0~9`、`Backspace` 刪除、`Enter` 直接開門！
- **BOSS 關 討伐魔龍**：
  - 魔龍口中噴射出**龍焰火球，在空中持續緩慢飄向勇者**！
  - 勇者在 1 分鐘內選出相同數值招式（支援快捷鍵 `1/2/3`），揮動神劍釋放蔚藍劍氣凌空斬滅火球並重創魔龍！
  - 若命數耗盡，【重生之盾】神力庇護涅槃重生！

### 3. 通關專屬稱號系統 (通關評價與頒發證書)
通關魔王關後，國王將根據勇者在全遊戲的綜合表現，親自授予專屬尊榮稱號，並展示於結算畫面、頒發榮譽勳章證書、紀錄於後台及 CSV 匯出：
- 👑 **神話級・算術大聖皇**：全關卡 9 星滿星、各關滿分 300 分且零失誤零重來之算術至尊！
- 🌪️ **疾風迅雷・神速破法使**：全關卡通關總時間極短（$\le 180$ 秒）之神速破法高手！
- ⚡ **四則奧義・大魔導劍士**：累計高星級與高積分，精通所有運算規則之魔法劍客！
- 🛡️ **浴火重生・鐵血聖騎士**：歷經多次觸發【重生之盾】涅槃重生，百折不撓終勝魔龍之鐵血戰士！
- 🐉 **王國守護・破龍大勇者**：成功擊退深淵魔龍、解救同伴之王國守護勇者！

### 4. 操作體驗與遊玩優化
- **鍵盤快捷鍵無縫支援**：
  - 第一關：`1`/`2`/`3` 或 `A`/`B`/`C` 選路，`Space`/`Enter` 跳過 3 秒等待。
  - 第三關：主鍵盤與數字鍵盤 `0~9` 輸入密碼，`Backspace` 刪除，`Enter` 立即開門。
  - 魔王關：`1`/`2`/`3` 快捷釋放招式，卡片標註快捷提示。
- **全裝置最佳適配**：手機觸控虛擬鍵盤、平板寬屏、電腦大螢幕極致流暢適配。

### 3. ID 自動分配與替補機制
- ID 格式：嚴格自 `AAA11111` 開始，依序遞增至 `AAA11112` ... `AAA99999`，進位至 `AAB11111`，一路直到 `ZZZ99999`。
- **系統自動分配，玩家不需自行填寫**。
- **流水號前進**：後按註冊的 ID 會是先按註冊的後一位，即使先按者未成功註冊亦會推進流水號。
- **空缺替補**：若某個 ID 玩家被刪除，後續註冊玩家會優先填補該空缺 ID！
- **重置歸零**：後台清空所有資料時，流水號重設回 0，下次註冊重新自 `AAA11111` 開始！

### 4. 伺服器分流系統 (001 ~ 999)
- 玩家於註冊或登入時可自由指定伺服器編號（例如班級代號 `001` 或 `403`）。
- 教師在後台可直接填入伺服器編號進行精準篩選，只查看該班級/分區的學生答題紀錄與成果！

### 5. 後台資料下載功能 (CSV / Excel 格式)
- 後台提供「📥 下載玩家答題資料 (CSV)」按鈕。
- 內建 UTF-8 BOM，下載後可用 Excel 或 Google 試算表直接開啟，完全不亂碼！
- 完整包含各關星數、最高分、最少花費秒數、最少答錯次數、累計重來次數、通關次數等所有數據。
